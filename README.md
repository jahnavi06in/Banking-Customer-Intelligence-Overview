# Banking Customer Intelligence Overview

## 📊 Project Overview

Banking Customer Intelligence Overview is an interactive business analytics dashboard designed to understand customer behavior, churn patterns, and customer segments.

The project uses data analysis, visualization, and K-Means clustering to identify meaningful customer groups and generate insights that can support customer retention and business decision-making.

## 🚀 Features

* Customer behavior analysis
* Customer churn analysis
* Interactive data visualizations
* Customer segmentation using K-Means clustering
* Customer profile analysis
* Business-focused customer insights
* Interactive Streamlit dashboard

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🎯 Project Objective

The objective of this project is to analyze banking customer data, identify customer segments, understand churn patterns, and present the findings through an interactive dashboard.

## ▶️ Run the Project

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run customer_segmentation.py
```
